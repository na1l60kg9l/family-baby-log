# 山西省人民医院运用新技术成功为一妇科肿瘤患者实施微创精准治疗

> 更新时间：2026-09-16 (UTC+8)

近日，山西省人民医院和平院区妇产科王素琴主任团队，运用前哨淋巴结示踪技术（sentinel lymph node biopsy  SLNB）成功为一名恶性肿瘤患者进行子宫内膜癌前哨淋巴结切除术，实现了妇科恶性肿瘤“微创精准治疗”。
56岁的患者张某，绝经后阴道流血2月，患有子宫内膜样腺癌，为求进一步治疗，入住和平院区妇产科。王素琴团队结合核磁及CT检查，综合评估后考虑子宫内膜子宫内膜样腺癌Ia期，属于子宫内膜癌早期。随后，进行腹腔镜下筋膜外全子宫切除术+双侧附件切除术+前哨淋巴结切除术，术中通过腹腔镜荧光显示器使用“吲哚菁绿”显影，点亮“盆腔前哨淋巴结”，并精准定位切除。在手术护理和麻醉团队的保驾护航下，手术顺利完成，经病房医护团队的精心护理，患者术后5天顺利出院。
前哨淋巴结作为“哨兵”，是原发肿瘤发生区域淋巴结转移必经的第一站淋巴结，临床上可通过SLN显影技术定位并活检，以便及时、准确地评估区域淋巴结是否发生转移。在传统手术中，除完整切除肿瘤病灶外，医生会行系统性淋巴结清扫术，常牵连无辜淋巴结而给患者带来不必要的伤害，且容易遗漏真正有问题的淋巴结。而前哨淋巴结活检能够更精准地评估淋巴结转移情况，使早期低危恶性肿瘤，如子宫内膜癌、宫颈癌，患者创伤更小、恢复更快、住院时间更短，提高临床治疗效果，更符合妇科肿瘤的微创理念。

此项技术已经成功用于子宫内膜癌，宫颈癌，将进一步将妇科恶性肿瘤做到精准和微创，降低医疗成本，促进患者快速康复。
