# 为什么生殖科要在月经期做阴道B超检查？

> 更新时间：2026-09-16 (UTC+8)

许多患者朋友都有这个疑问，阴道B超不是应该避开月经期吗？怎么在生殖内分泌科阴道超声会在月经第2天或是第3天做呢？特别是促排卵进周期时更是要求在月经期做超声检查。

这究竟是为何呢？

一起来听听医生怎么说！

**01**

[

**经期检查的优势**]

1. 显示更清晰：相较于经期进行腹部 B 超，阴道 B 超检查更接近盆腔脏器，其分辨率也更高，显示会更为清晰。而且无需憋尿排空膀胱，能减轻憋尿的痛苦，减少肠道气体造成的干扰。

2. 窦卵泡计数，了解女性卵巢功能：对两侧卵巢内的基础窦卵泡数目进行计数，以评估患者的卵巢功能。若两侧窦卵泡数小于 5-7 枚，则考虑卵巢储备功能下降，结合月经期的性激素化验检测及AMH值结果，做出进一步评估。

此外，对于一侧或双侧卵巢内直径2-9mm的卵泡数目≧12 个的姐妹，需考虑卵巢多囊样改变的情况。我们需要结合月经史、高雄激素血症的临床表现以及化验检查等方面，判断是否存在多囊卵巢综合征（PCOS）。

3. 了解卵巢病变，避免干扰：在经期评估卵巢状况具有一定优势，能有效避免大的优势卵泡、滤泡囊肿及黄体囊肿等非经期容易出现的情况所带来的干扰。

4. 评估卵泡发育的同步性：有些方案需要了解女性基础卵泡的情况，从而制定相应的用药时间、选用何种药物等。对于上一周期促排卵中出现卵巢过度刺激倾向的患者，可在本次月经期通过超声检查了解卵巢恢复情况，以便制定下一步处理方案。

   

**02**

[

**阴道 B 超安全吗？有无必要？能否等经期结束再做？**]

不少患者对阴道 B 超存在一定恐惧，担心检查不卫生，给自己留下心理阴影。请姐妹们放心，医生在做检查前，都会更换检查手套、消毒垫巾及检查所用的避孕套，并在单独房间拉上隐私帘进行检查。

生殖科医生选做阴道B超会选在月经的第二或是三天进行。

一方面是因为在此时间，新的月经周期刚开始，卵泡在募集之中，新一轮卵泡尚未开始生长和优选，属于卵巢的基础状态。这期间进行阴道超声检查，主要是观察双侧窦卵泡的数目（窦卵泡指的是直径 2 - 9mm大小的卵泡），了解卵巢的储备功能情况。可为临床诊断多囊卵巢综合症、卵巢功能下降等诊断提供一定的依据，同时结合基础内分泌相及AMH值，能协助确定助孕方法及用药方案。

此外，还能了解子宫内膜的剥脱情况，同时为促排卵、冻胚移植等确定方案提供依据。

**03**

[

**做阴道 B 超检查时，需注意的事项**]

**注意!!**

1、检查前要排空膀胱，膀胱内的尿液会造成超声波干扰及产生超声波伪像。

2、检查当天，建议穿舒适宽松、易于穿脱的衣服，避免穿裤口过紧的衣物，别穿连体裤、长筒靴等。

3、检查时，建议尽量放松身心，不要过度紧张或焦虑，积极配合医生，如有任何疑问，应及时向医生咨询。
